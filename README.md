## 🚀 What is nethack-tiles-client?

nethack-tiles-client is a desktop application that lets you play **NetHack**, one of the most famous roguelike games ever created, with colorful graphical tiles instead of boring ASCII characters. You connect to public servers automatically, so you don't need to install or configure anything complicated.

This app works on **Windows, macOS, and Linux**. It is designed for people who want to experience NetHack without dealing with technical setup. Just download, open, and start playing.

## 🎮 Features

- **Graphical Tiles** – See monsters, items, and dungeons as beautiful icons instead of letters and symbols.
- **One-Click Connect** – Automatically connects to public NetHack servers. No need to set up SSH or anything.
- **Built-in Terminal** – The game runs inside a modern terminal emulator (xterm.js) embedded in the app.
- **Cross-Platform** – Works on Windows, macOS, and Linux.
- **Regular Updates** – New tiles and improvements added often.
- **No Installation Required** – Download and run. No admin rights needed.

## 🎯 How to Play

1. Launch the application.
2. You will see a terminal window. Type your name and press Enter.
3. Choose a character class (like Warrior, Mage, or Rogue) by typing the first letter.
4. Choose a race (like Human, Elf, or Dwarf).
5. Choose an alignment (Lawful, Neutral, or Chaotic).
6. The game starts. You are in the dungeon. Use the arrow keys to move.
7. Press `?` for help at any time.

### Basic Controls
- **Arrow Keys** – Move your character
- **Space** – Wait (rest) one turn
- **g** – Get (pick up) an item
- **d** – Drop an item
- **i** – Show inventory
- **e** – Eat food
- **w** – Wear armor or wield a weapon
- **q** – Quaff (drink) a potion
- **z** – Zap a wand
- **>** – Go down stairs
- **<** – Go up stairs
- **?** – Help menu

## 🌐 Connecting to Servers

The app automatically connects to the **dgamelaunch** public servers. You don't need to set up SSH or anything. Just start the app and you're online.

Your game saves are stored on the server, so you can continue playing from any computer using the same username.

## 🛠️ Troubleshooting

### App won't start
- Make sure your antivirus isn't blocking the app. Add an exception if needed.
- Try running as administrator (right-click, Run as administrator).
- Reinstall the app from the download page.

### No tiles showing
- The app updates tiles automatically. If they don't appear, restart the app.
- Check your internet connection.

### Game is slow
- Close other programs to free up memory.
- Reduce the terminal font size in the app settings.

### Can't connect to server
- Check your internet connection.
- The public servers might be down for maintenance. Try again later.
